About This Demo

This is a fully static, pre-computed demo of a production-grade Retrieval-Augmented Generation (RAG) system. The pipeline processes PDF and DOCX documents through multiple retrieval stages to find the most relevant passages for any query.

Architecture: Documents are chunked (512 tokens, 128 overlap), embedded using BGE-small-en-v1.5 (384d vectors), and stored in ChromaDB. At query time, the system performs hybrid retrieval (dense vectors + BM25), fuses results with Reciprocal Rank Fusion (RRF, k=60), applies MaxSim token-level scoring, and reranks with a cross-encoder. HyDE (Hypothetical Document Embeddings) optionally expands queries for better semantic matching.

Key Innovation: The multi-stage pipeline dramatically improves retrieval quality over naive vector search. Each stage can be toggled independently — use the settings panel above to see how each component contributes to overall precision.
